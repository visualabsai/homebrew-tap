# visualabsai homebrew tap

Homebrew formulae and casks for [visualabsai](https://github.com/visualabsai) tools.

```sh
brew tap visualabsai/tap
```

## Available

### agentdeck

One dashboard for every CLI coding agent on your machine — Claude Code, Codex
CLI, Gemini CLI, OpenCode, and local models via aider + Ollama.

```sh
brew install visualabsai/tap/agentdeck
```

Source: [visualabsai/agentdeck](https://github.com/visualabsai/agentdeck)
